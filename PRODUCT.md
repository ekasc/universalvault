# UniversalVault

## Register

product

## Users and purpose

Mac users save structured personal information locally and insert individual values into other applications without using the clipboard. The primary workflows are organizing items, editing typed fields, quick fill, locking, and encrypted backup recovery.

## Design principles

- Protect private values before optimizing convenience.
- Use native macOS controls, system typography, system accent, and standard keyboard behavior.
- Keep saved data intact when authentication, validation, or persistence fails.
- Show busy, locked, empty, error, and recovery states explicitly.
- Do not add public sharing, Spotlight indexing, or remote services to a private vault.

## Accessibility

Controls need names and keyboard operation. Selection and sensitivity must be announced, not conveyed only through color. Support light and dark appearances and system accessibility preferences. Native VoiceOver acceptance requires observed behavior, not source inspection.
